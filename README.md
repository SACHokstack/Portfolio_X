# 🚀 AI Freelancer Portfolio - Hero Section

A cinematic, interactive Hero section for a personal portfolio website featuring:

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** for smooth animations
- **Three.js** via `react-three-fiber` for 3D starfield

## 🎬 Features

- **Dynamic 3D Starfield Background**: Slowly rotating stars create an immersive cosmic atmosphere
- **Staggered Text Animations**: Smooth fade-in and slide-up effects using Framer Motion
- **Mouse Parallax**: Content and cursor glow follow mouse movement for depth
- **Floating AI Particles**: Glowing orbs drift across the hero section
- **Interactive CTAs**: Buttons with hover effects, scaling, and glowing borders
- **Responsive Design**: Works seamlessly on mobile and desktop
- **Custom Fonts**: Orbitron for headings, Poppins for body text

## 📦 Installation

```bash
npm install
```

## 🏃 Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## 🎨 Key Components

- **`components/Hero.tsx`**: Main hero section with Framer Motion animations
- **`components/Starfield.tsx`**: Three.js starfield background with rotating stars
- **`app/layout.tsx`**: Root layout with Google Fonts (Orbitron + Poppins)

## 🎭 Animations

- Staggered text reveals with custom easing
- Floating cosmic drift effect on content
- Mouse parallax for depth perception
- Cursor glow follows mouse position
- Button hover with scale and glow effects
- Scroll indicator with bounce animation
